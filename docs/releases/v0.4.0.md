# v0.4.0 — 多站点与推送队列

## 需求

1. 百度推送按**每日额度**续传，全部完成后**自动新一轮**。
2. 支持**多站点**配置与切换，界面更易用、视觉升级。
3. 精简冗余环境变量配置。
4. 明确腾讯云部署后定时任务行为，提供 SCF 方案。

## 完成情况

- 队列持久化于 `data/push-queue/{siteId}-baidu.json`，`pickNextBatch` 受 `baiduDailyLimit` 约束。
- `npm run schedule:run` / `schedule:daemon` 遍历 `config/sites.json` 中启用百度的站点。
- 总览与百度页展示队列进度；顶栏站点切换（Cookie `seo-active-site`）。
- `docs/deploy-tencent.md`：说明构建部署**不会**自动启动守护进程；推荐 SCF 定时触发器。

## 遗留问题

- Bing 提交尚未接入同一队列模型（backlog v0.4.1）。
- SCF 生产环境需将 `data/push-queue` 迁至 COS 或挂载盘（当前为本地文件）。
- 从 `secrets.env` 迁移：运行 `node scripts/migrate-sites-secrets.js`。
