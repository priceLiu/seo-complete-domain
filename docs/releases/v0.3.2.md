# v0.3.2 发布说明

**发布日期**：2026-05-19  
**标签**：`v0.3.2`

## 1. 需求

提供开箱即用的本地环境：**仓库内默认配置文件** + **安装依赖时自动生成 `.env.local`**，用户只需 `npm install` 与 `npm run dev`。

## 2. 计划

| 序号 | 任务 | 状态 |
|------|------|------|
| E1 | 新增 `config/app.env`（可提交） | 完成 |
| E2 | `scripts/ensure-env.js` + `postinstall` | 完成 |
| E3 | README / `.env.example` 说明 | 完成 |

## 3. 完成情况

- 首次 `npm install` 若不存在 `.env.local`，则从 `config/app.env` 复制；不覆盖已有 `.env.local`。  
- CI 可用 `SEO_SKIP_ENV_BOOTSTRAP=1` 跳过。

## 4. 遗留问题

- Bing / 百度密钥仍需用户在 `.env.local` 中自行填写（不向仓库写入密钥）。
