# v0.4.1 — Bing 队列 + 云函数可部署

## 需求

1. 实施可部署的腾讯云 SCF 定时推送。
2. Bing 接入与百度相同的队列模型；其他引擎统一扩展点。

## 任务进度

| 任务 | 状态 |
|------|------|
| `lib/queue-runner.js` 通用队列执行器 | 完成 |
| `lib/run-queue-bing-push.js` + `lib/push-engines.js` | 完成 |
| `npm run scf:package` → `dist/scf-seo-push.zip` | 完成 |
| UI：百度/Bing 双队列卡片 | 完成 |
| 守护进程 / CLI 多引擎 | 完成 |

## 完成情况

- 队列文件：`data/push-queue/{siteId}-baidu.json`、`{siteId}-bing.json`。
- `npm run schedule:run` 对每个站点跑 **baidu + bing** 各一批。
- SCF：`scf/seo-push/index.js`，打包脚本 `scripts/scf-package.js`，文档 `docs/deploy-tencent.md`。
- 环境变量：`PUSH_QUEUE_DIR`、`SITES_JSON`、`SITES_SECRETS_JSON` 支持无文件部署。

## 遗留

- SCF 生产务必 COS 挂载 `PUSH_QUEUE_DIR`，否则 `/tmp` 队列跨日丢失。
- 新增引擎：在 `lib/push-engines.js` 注册 `RUNNERS` 即可。
