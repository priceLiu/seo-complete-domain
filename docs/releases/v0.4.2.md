## 完成情况

- 根因：站点 sitemap 约 **257** 条，百度普通收录 API 当日配额约 **9** 条（`success:1` + `remain:8`）；Sitemap 模式默认一次抓 **500** 条并整批 POST → `over quota`，并非「昨天没推过却扣额度」的 bug。
- 代码：`lib/baidu-push.js` 配额感知分批；`lib/run-queue-baidu-push.js` 结果与真实推送对齐。
