# v0.3.1 发布说明

**发布日期**：2026-05-19  
**标签**：`v0.3.1`

## 1. 需求

站点已在百度搜索资源平台验证时，希望 **环境变量开箱即用**：直接把平台提供的 **整段接口调用地址** 配进 `.env.local`，无需再手工拆分 `site` / `token`。

## 2. 计划

| 序号 | 任务 | 状态 |
|------|------|------|
| C1 | `getBaiduPushCredentials()`：解析 `BAIDU_PUSH_API_URL`，优先于分项变量 | 完成 |
| C2 | 更新 `/api/baidu/config`、`/api/baidu/push`、面板与 README、`.env.example` | 完成 |

## 3. 进度跟踪

| 日期 | 说明 |
|------|------|
| 2026-05-19 | C1–C2 完成 |

## 4. 完成情况

- 新增 **`BAIDU_PUSH_API_URL`**：`http://data.zz.baidu.com/urls?site=...&token=...`（与平台复制一致即可，`site` 可为 URL 编码形式）。  
- 仍支持 **`BAIDU_PUSH_TOKEN` + `BAIDU_PUSH_SITE` / `NEXT_PUBLIC_SITE_URL`**；整段 URL 与分项同时存在时，**优先整段 URL**。  
- `GET /api/baidu/config` 增加 **`configSource`**：`api_url` | `parts` | `none`，便于确认当前读取方式。

## 5. 遗留问题

- 若用户粘贴的地址被截断或参数名非 `site`/`token`，解析失败会回退到分项配置；需在文档中提示核对。  
- 与 v0.3.0 相同：索引类数据无官方稳定拉取 API。

## 6. 配置示例

```bash
# 推荐（站点已验证，直接粘贴平台「接口调用地址」）
BAIDU_PUSH_API_URL=http://data.zz.baidu.com/urls?site=https%3A%2F%2Fwww.example.com&token=your_token_here
```
