# v0.1.0 发布说明

**发布日期**：2026-05-19  
**标签**：`v0.1.0`

## 1. 需求

- 弃用原 CloudBase 云函数方案，清理不可用依赖与代码。  
- 新建单库 **Next.js + ECharts**，样式统一、简洁。  
- 支持目标站（默认 `https://www.ai-code.com`）的 **页面 SEO 审计**（规则打分 + 修复建议）。  
- 提供 **百度 / Bing 收录** 模块的说明与后续对接入口（本版不接真实索引 API）。  
- 建立 **版本迭代规则**：需求、计划、进度、完成情况、遗留问题、发版文档。

## 3. 进度跟踪

| 日期 | 说明 |

## 4. 完成情况

- 已移除全部 **CloudBase 云函数** 与旧 `nextjs-frontend`。  
- 审计结果持久化：`data/audit-latest.json`（目录已 `.gitignore`）。  
- 环境变量示例：`.env.example`（`NEXT_PUBLIC_SITE_URL`、`AUDIT_USER_AGENT`、预留 `BING_WEBMASTER_API_KEY`）。  
- UI：**CSS 变量**统一配色与卡片布局；ECharts **SVG** 渲染柱状图。

## 5. 遗留问题

- **Bing**：未接入 Webmaster API，需后续实现服务端同步与图表。  
- **百度**：未实现自动索引拉取（公开 API 受限）；需产品策略（人工同步或爬虫日志）。  
- **审计深度**：当前为规则引擎；未集成 Lighthouse，可参考 `site-audit-seo` 等开源增强。  
- **部署**：未配置 CI/CD；`maxDuration` 在自托管需按平台调整。  
- **鉴权**：API `/api/audit/run` 未加口令，生产环境需加中间件或密钥。

## 6. 升级方式

```bash
cp .env.example .env.local
# 编辑 NEXT_PUBLIC_SITE_URL
npm install && npm run dev
```

在「页面审计」页点击「开始审计」生成数据。
