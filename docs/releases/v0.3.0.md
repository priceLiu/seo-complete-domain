# v0.3.0 发布说明

**发布日期**：2026-05-19  
**标签**：`v0.3.0`

## 1. 需求

- 按百度搜索资源平台公开能力，接入 **URL 主动推送 HTTP API**（`data.zz.baidu.com/urls`），与既有 Bing 能力并列。  
- 支持 **普通收录** 与可选 **`type=daily` 快速收录**（需在平台开通权益）。  
- **索引量、抓取诊断等**仍以站长后台为准（无稳定、文档完备的公开拉取 API）。

## 4. 完成情况

- 文档入口：<https://ziyuan.baidu.com/linksubmit/index>；接口协议：POST、`Content-Type: text/plain`，正文每行一个 UTF-8 URL，单次最多 2000 条（以平台最新说明为准）。  
- 环境变量：`BAIDU_PUSH_TOKEN`（必填）、`BAIDU_PUSH_SITE`（可选，须与平台「API 提交」里的 `site=` **完全一致**）。  
- 若配置了 `AUDIT_RUN_SECRET`，推送接口与审计接口同样要求 Bearer / body `secret`。

## 5. 遗留问题

- **索引/抓取统计**：百度未提供与 Bing Webmaster 对等的公开 JSON 统计 API；若后续官方开放，可再增只读模块。  
- **`site` 格式**：不同账号可能是 `https://www.a.com`、纯域名等，依赖用户用 `BAIDU_PUSH_SITE` 与后台保持一致。  
- **网络策略**：默认请求 `http://data.zz.baidu.com`（与官方文档一致）；若部署环境禁止明文 HTTP，需自行评估代理或隧道。

## 6. 配置示例

```bash
BAIDU_PUSH_TOKEN=你在资源平台复制的 token
# 若平台接口里是 site=www.example.com，而 NEXT_PUBLIC_SITE_URL 为 https://www.example.com，请显式设置：
# BAIDU_PUSH_SITE=www.example.com
```
